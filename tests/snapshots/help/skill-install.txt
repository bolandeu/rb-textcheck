
 Usage: textcheck skill install [OPTIONS]

 Copy this CLI's bundled SKILL.md into an AI tool's skill directory.

 Example: textcheck skill install --tool claude-code

╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --tool           <str>  Target AI tool: one of claude-code, agents. [default: claude-code]       │
│ --project               Install into the current project instead of the user-level directory.    │
│ --json                  Emit machine-readable JSON output.                                       │
│ --quiet                 Suppress non-essential output.                                           │
│ --help                  Show this message and exit.                                              │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
